# -v.1.1-
一个纯本地的小型词典 / 生词本应用：查词（中英互查、释义、音标、发音）＋ 生词本（加词、排序、记忆次数、一键隐藏中文）。原理与设计参考自 **灵格斯词霸（Lingoes 2.8.1）**，并直接复用其部分组件与资源。

技术形态：Python 3.13 纯标准库（零第三方依赖）+ 本地 HTTP 服务 + Edge 无地址栏应用窗口。

## 快速开始

- **双击 `生词本.vbs`** —— 正常使用入口（无控制台，日志写入 `data\app.log`）。
- 双击 **`生词本-调试.bat`** —— 带控制台排错用。

应用会启动本地服务→ 打开一个独立的 Edge 应用窗口（无地址栏、独立配置，不影响你日常浏览器）。

**关闭窗口即退出应用**（离开页面 30 秒后自动清理进程；有 12 小时硬上限兜底）。窗口已关闭但想立刻退出：设置 → 退出应用。

## 功能

### 查词
- 输入英文或中文，回车。英文出 美/英音标、释义（按词性分列）、词形变化、柯林斯英英释义（带中文对照）、短语、双语例句、网络释义；中文出 拼音、汉英释义、吴光华汉英、例句。
- **发音**：美音 / 英音（在线真人音源）；中文词为「朗读」。例句用系统合成音。发音降级链：在线音源 → 本地语音库（真人 mp3）→ 系统 TTS 合成，断网也能大部分可用。
- 查询结果自动缓存，重复查词秒回；结果页「↻ 刷新」可忽略缓存重新在线查询。
- **类别后缀查询（v1.1）**：词后加 `-2` 查**相关词组**（`go-2` → go out / go on / …；中文如 `电脑-2`），加 `-3` 查**形近 / 易混淆词**（`through-3` → throughout / thorough / trough；中文如 `电脑-3` 查长相接近的词）；`-1` 与不加后缀相同。`F-16` 这类本身含 `-` 的词不受影响。
- 短语 / 相关词组 / 形近词表格里**点任意一行即直接查询该词**；普通查词结果头还有「🔎 查相关词组」快捷键。
- **查询提速（v1.1）**：多源并发 + 等待预算，单语冷查一般 1–3 秒返回（原约为 5–10 秒）。

### 生词本
- 查词结果页点 **「＋ 加入生词本」**；加入时会保存一份释义快照，**离线也能看翻译和发音**。
- 排序：**按字母 / 拼音**（中文按无调拼音，如 电脑→diannao，英文在前）、按添加时间、按记忆次数；支持升 / 降序与筛选。
- 每条：🔊 发音、`+1` 复习计数、`×N` 点击直接改次数、**详情**（释义快照 + 备注 + 重新获取释义）、🗑 删除。
- 顶栏 **👁 隐藏中文**：一键隐藏所有中文释义（生词本里自测记忆用），设置持久保存。
- **导入灵格斯历史**：把灵格斯词典的查询历史一键导入生词本（自动去重）。

### 设置
- 中 / 英文发音的语音（SAPI）、语速。
- 真人语音库目录（支持多目录；目录里放 `单词.mp3` 即可被识别）。
- **ECDICT 离线词库**（62.9MB，MIT 许可）：下载后可离线查 77 万词条，作为在线查询的兜底。下载中断了也没关系——重新打开应用会自动续传。
- 灵格斯安装目录（拼音排序 / 笔画 / 历史导入的数据源）。
- **返回旧版 v1.0.0**（设置 → 应用）：一键把程序文件还原为初始 v1.0.0 并自动重启，**生词 / 设置 / 备注等数据不受影响**；还原前会自动再存一份当前版本，之后可随时切回。界面打不开时，也可以双击根目录的 **`返回旧版.bat`** 冷还原。

## 数据与备份

全部数据在本目录 `data\` 下，**备份生词本只需拷 `data\vocab.json`**。

代码快照在 `backup\`：`v1.0.0_2026-10-13\`（初始版）、`v1.1.0_2026-10-13\`（当前版）、`pre_restore_*\`（每次还原前自动留存）。快照只含程序文件，不含任何数据。

| 文件 | 内容 |
|---|---|
| `data\vocab.json` | 生词本（含释义快照、备注、记忆次数） |
| `data\cache.json` | 查词缓存（可删，最多 3000 条 LRU） |
| `data\settings.json` | 设置 |
| `data\speech_index.json` | 语音库索引（可重建） |
| `data\app.log` | 运行日志（512KB × 3 轮转） |
| `data\ecdict\` | 离线词库（可删，重新下载） |
| `data\audio\` `data\tts\` | 发音缓存（各 200MB 上限自动清理） |
| `data\browser-profile\` | 应用窗口的独立浏览器配置 |

## 断网时能用什么

- 已查过的词（缓存）✅　生词本里所有词（快照）✅　发音：本地语音库 + 系统 TTS ✅
- ECDICT 已下载的话：离线查词 ✅　灵格斯历史导入 ✅（导入时无法自动取释义，可稍后点详情里「重新获取释义」）

## 复用自灵格斯词霸的组件

| 灵格斯组件 | 本应用用法 |
|---|---|
| `speech\sample\`（真人语音 mp3 + voice.ini） | 拷入 `assets\speech\`，作为本地语音库；`RedirectPath` 语义保留（可在设置里指向外部语音目录） |
| `appe\zhstroke\stroke.js`（2 万+ 汉字的笔画/部首数据） | 解析为笔画/部首数据（查词接口 `/api/lingoes/pinyin`） |
| `appe\pinyin\py.js`（汉字→拼音） | 中文生词排序键（无调拼音）、拼音展示 |
| `webe\webengine-*.txt`（在线词典引擎模板，含 `[$key]` 占位） | 设置里可开启「在线词典外链」，查词页生成引擎链接 |
| `data\user.ini` 的查询历史 | 「导入灵格斯历史」按钮 |

## 署名与许可

- 在线中文释义 / 真人发音：**有道词典**（仅供个人学习使用）。
- 英英释义 / 部分录音：**Free Dictionary API / Wiktionary**（CC BY-SA 3.0）。
- 离线词库：**ECDICT**（MIT License，github.com/skywind3000/ECDICT）。
- 笔画 / 拼音数据、语音样例：来自本机安装的**灵格斯词霸**，仅个人本机使用。

## 常见问题

- **窗口关了但进程还在？** 最多 30 秒后自动退出（心跳看门狗）。想立即退出：设置 → 退出应用。
- **查询提示「本地服务已断开」/ 页面出现「本地服务已停止」浮层？** 后台服务已退出（关闭窗口约 30 秒后就会自动退出）。双击 `生词本.vbs` 重新启动即可；服务一恢复，原页面会自动继续，也可以点浮层里的「重试连接」或手动刷新。
- **端口被占用？** 自动从 17800 向后找可用端口，全占则随机端口，无需干预。
- **下载 ECDICT 卡住？** 会自动在 3 个下载通道间切换重试；也可手动把 `ecdict.csv` 放到 `data\ecdict\` 后点「重建索引」。
- **不装 ECDICT 行不行？** 行，只是断网时查不了新词；不影响其他所有功能。
- **想回到旧版 / 改坏了怎么办？** 设置 → 应用 →「返回旧版 v1.0.0」（自动还原程序并重启）；界面打不开时双击 `返回旧版.bat`。想再切回新版：把 `backup\` 里最新 `pre_restore_*\` 或 `v1.1.0_*\` 快照目录中的文件全部拷回本目录覆盖即可。数据（`data\`）全程不受影响。
